REPORTING FEATURES (Guideline 1.2)

Report a Post
Find any post in the feed
Tap the 3-dot menu (⋮) in the top-right of the post
Tap "Report Post"
Select a reason from the list
Confirmation: "Thank you for your report. Our team will review it within 24 hours."

Report a Comment
Expand any post to view comments
Long-press on any comment (hold for ~0.5 seconds)
Select a reason from the report modal
Confirmation message appears

Report a User
Tap on any username to visit their profile
Below their bio, tap the "Report" button
Select a reason from the list
Confirmation: "Thank you for your report. Our team will review it within 24 hours."

Report a Chat/DM
Open any chat conversation
Tap the 3-dot menu (⋮) in the chat header
Tap "Report User" (for DMs) or "Report Chat" (for groups)
Confirm the report

Report a Help Message
Go to Towny (Menu → Towny)
Long-press on any message
Tap "Report Message"
Report an Ad
Find any advertisement in the feed
Tap the flag icon on the ad
Select a reason from the list

BLOCKING FEATURES (Guideline 1.2)

Block from Post
Tap the 3-dot menu (⋮) on any post
Tap "Block User"
Select a reason
User is blocked - you won't see their content

Block from Profile
Visit any user's profile
Tap the "Block" button below their bio
Select a reason
User is blocked

Block from Chat
Open a chat conversation
Tap the info icon
Tap "Block User"

Manage Blocked Users
Settings → Blocked Users
Can unblock any user from this list

CONTENT MODERATION
Automatic Filtering
All posts pass through AI moderation before publishing
Posts are either: Approved, Rejected, or Held for manual review
Rejected posts show reason to user

Manual Review
Admin panel for moderators to review flagged content
Reports reviewed within 24 hours (stated in Guidelines and Privacy Policy)
Actions: Approve, Reject, Blur, Delete, Warn user, Mute user, Ban user

User Notifications
Users receive notifications when moderators act on their content or reports
Notifications explain what action was taken and why
